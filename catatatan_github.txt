github adalah sebuah website tempat berbagi project bermacam-macam source code

selain Github (microsoft)
ada gitlab, bitbucket (atlassian), gitkreker

Fungsi  utama Github:
1.  Menyimpan source code secara online/cloud
2.  Kalaborasi antar developer
3.  tools/alat untuk menarik source code ke server
4.  versioning > bisa kembali ke versi sebelumnya

Status dalam git:
U / Untracked = File yang belom terdeteksi oeleh sistem git
M / Modifiled = File yang sudah existing, di modifikasi/dilakukan perubahan isi file
A / Addeed    = File yang sudah masuk/strage add
Langkah-langkah me girim source code ke github:
1. add      = Keluar 
2. Commit   = Proses
3. Push     = Masuk

Langkah-langkah menghubungkan repo baru di lokal & server github
git init => mendaftarkan repo lokal kita sebagai repo yang sudah memakai sisystem git
git branch -M main = mengganti cabang utama dengan nama main
git remote add origin https://github.com/muhammadnurfaizi/jfd_jan26_nodejs_basic.git = menghubungkan repo lokal dengan 
git config --global user.email "faiz130201@gmail.com
git config --global user.name"muhammadnurfaizi"
git add. => menambah semua file
git.commit -m "pesan commit"
git push -u origin main = finalisasi pengiriman source code

jika push kedua kali cukup ketik perintah git push

Syarat kolaborasi:
1. invite developer ke repo kita
2. narik perubahan dari collaboratior lain: git pull
